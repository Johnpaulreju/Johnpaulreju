## October 2026

- **Oct 8 · Easier invitations in Mafia Imposter.** Players can copy a room code or an invite link from the waiting room and send it to a friend. [See the invitation change](https://github.com/Johnpaulreju/mafia_imposter/commit/89b25bf5bd5008820556d3bccd9aa854f75cb844)
- **Oct 5 · A lobby that survives its host leaving.** If the host leaves before a round starts, Mafia Imposter hands the room to another connected player so the group can carry on. [See the host handoff](https://github.com/Johnpaulreju/mafia_imposter/commit/a98a06067c018298a886ab021696226eaadc6f42)
- **Oct 1 · Better previews for shared shop links.** On the From The Trunk team, I updated the images that appear when someone shares a collection or content page and added tests for missing images. [Read merged pull request #73](https://github.com/Odyssey-Therapeia/fromthetrunk-website/pull/73)
